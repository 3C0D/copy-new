# rules.md

Quand tu exécutes un script dans ce projet Tu utilises Python Qui se trouve dans L'environnement virtuel Windows_and_Linux\myvenv\Scripts\python.exe 
Donc tu n'as pas besoin d'installer des dépendances. 
Si tu dois installer des dépendances, tu les rajoutes dans le fichier requirements.txt et utilise Windows_and_Linux\scripts\update_deps.py
Si on te demande d'améliorer l'aide Tu consultes le MCP Memory Pour voir les directives Concernant la mise à jour de l'aide.
