# rules.md

Quand tu exécutes un script dans ce projet Tu utilises Python Qui se trouve dans L'environnement virtuel Windows_and_Linux\myvenv\Scripts\python.exe Donc tu n'as pas besoin d'installer des dépendances Si tu dois installer des dépendances, tu les rajoutes dans le fichier requirements.txt et tu exécutes la commande pip install -r requirements.txt

Pour les installations de dépendance Utilise le script Windows_and_Linux\scripts\update_deps.py
